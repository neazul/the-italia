# The Italia — HTML, CSS & JavaScript

A static multi-page-style restaurant website implemented as a single-page experience with six page views:
Home, About, Menu, Gallery, Reservation, and Contact.

## Run it
- Open `index.html` directly in your browser, or use VS Code Live Server.
- No npm install or build step is required.

## Features
- Responsive layouts for desktop and mobile
- Page navigation without a framework
- Menu category filtering
- Gallery image lightbox
- Favorite toggles on menu cards
- Reservation and contact form demo confirmations
- Italian-inspired forest green, cream, burgundy, and gold palette

## Important
The reservation/contact forms are front-end demos only; they do not submit to a backend, email service, or booking system. Food photography and Google Fonts are loaded online.
